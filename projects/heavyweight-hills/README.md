# Heavyweight Hills — Movember 2026 launch video

James Leahy's Movember campaign: up and down local hills in a 30 kg vest, asking for sponsorship for a summit.
Donations: <https://movember.com/m/15440871?mc=60> (the QR code on the end card goes here).

## What is (and isn't) in this folder

This repo is public, so **raw footage and voice recordings are deliberately not committed** (`.gitignore` blocks them).
Kept here: the edit itself, so it can be re-rendered or changed.

- `film/index.html` — the huashu-motion composition: every shot, in/out point, title, sound effect and timing.
- `film/vendor/`, `film/assets/fonts/` — runtime + fonts (Merienda titles, Outfit labels; OFL licensed). Title style follows `brand/`.
- `film/assets/qr.svg` — QR code for the Mo Space link.
- `voiceover/vo_plan.json` — where each voice-over phrase sits on the timeline; `build_vo.py` assembles it.

## Rebuilding the edit

Needs: Node ≥ 22, FFmpeg, Chrome/Chromium, and the huashu-motion CLI (`vendor/huashu-motion` in this repo:
`.claude/skills/huashu-motion/bin/om`).

### 1. Put the clips back in `film/assets/clips/`

Edit copies are 1080×1920, 30 fps, H.264, no audio, made from the iPhone originals:

```sh
ffmpeg -i IMG_XXXX.mov -an -vf "fps=30,scale=1080:1920,format=yuv420p" \
  -c:v libx264 -preset veryfast -crf 18 -g 15 -movflags +faststart film/assets/clips/XXXX.mp4
```

### 2. Rebuild the voice track (`film/assets/voice.wav`)

Main read: take 5 (`New Recording 5`); "By day / In the rain / By night": `New Recording 6`, reordered to match the shots.
`python3 voiceover/build_vo.py voiceover/vo_plan.json <take5-transcript.json>` prints the ffmpeg filter that
places each phrase; the extra three lines were added at 13.62 s, 15.62 s and 17.62 s, level-matched.

### 3. Music, render, master

```sh
om sound film          # writes assets/sound.wav (synthwave, 120 BPM), ducked under the voice cues
om render film         # → film/out/film-vN.mp4
om qa film
```

Then the final mix (v12, voice-forward):

- Music + effects bus: `sound.wav`, lifted 1.2× from 13.45–19.9 s (the night drop), then side-chain ducked by the
  voice (`sidechaincompress=threshold=0.04:ratio=3:attack=10:release=300`) so the title hits don't mask words.
- Voice: `highpass=100`, −2 dB at 250 Hz, +4 dB at 3.2 kHz, `acompressor` 4:1 with +6 dB makeup, limiter at −0.9 dB.
- Sum, then two-pass `loudnorm` to −14 LUFS / −1.5 dBTP, AAC 256k. Every word ends up ≥ ~12 dB above the music.

v10/v11 had the voice only ~10 dB over the music and the title impacts landing on words, which made it hard to hear.

### 4. The 15 s cutdown

Cut from the 30 s master at these beats (source seconds): `0–2.5, 3.0–4.5, 6.0–7.5, 7.5–10.5, 23.5–24.5,
24.5–30.0`, joined with 12 ms audio fades.
