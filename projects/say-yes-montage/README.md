# Say Yes — personal montage (Nov 2026)

Two vertical montages (1080×1920, H.264 + AAC 256k, −14 LUFS) cut from 16 iPhone clips, in the house style from
`brand/` (Merienda Black titles, #75FF78 accent word, Outfit labels, down-right shadow, no text below y 1440).

| File | Length | Notes |
|---|---|---|
| `videos/Say-Yes-30s.mp4` | 30 s | 16 shots on a 120 BPM grid, 10 titles, 5 s end card |
| `videos/Say-Yes-10s.mp4` | 10 s | Hook, 8 beat cuts, 2.5 s end card |

Music and sound effects are generated by huashu-motion; no voice-over; clip audio muted.

## Rebuilding

Raw footage is not committed (`.gitignore`). Edit copies go in `clips/` and are copied to `film-*/assets/clips/`.
The iPhone originals are HLG HDR, so tone-map them to SDR first:

```sh
TM="zscale=t=linear:npl=203,format=gbrpf32le,zscale=p=bt709,tonemap=mobius:desat=0:param=0.3,zscale=t=bt709:m=bt709:r=tv"
ffmpeg -i IMG_XXXX.mov -an -vf "$TM,fps=30,scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,format=yuv420p" \
  -color_primaries bt709 -color_trc bt709 -colorspace bt709 -c:v libx264 -preset veryfast -crf 18 -g 15 clips/XXXX.mp4
# end-card background: clips/2148_loop.mp4 = 2148 forward then reversed
```

Then edit the cut lists in `build.py` (shots, titles, end-card time) and:

```sh
python3 build.py                  # writes film-30/index.html and film-10/index.html from template.html
om sound film-30 && om render film-30
om sound film-10 && om render film-10
```

Final master: two-pass `loudnorm` to −14 LUFS / −1.5 dBTP, trimmed to exact length.
